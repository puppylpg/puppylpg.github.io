# 对话归档文章最小模板

本模板只提供 Jekyll 文件骨架，不规定正文结构。使用时替换所有占位内容，并根据知识依赖自行设计章节；不要把占位标题机械地保留在文章中。

```markdown
---
title: "<直接、准确、可检索的文章标题>"
date: <执行 date 命令得到的时间>
categories: [<按目标目录填写>]
tags: [<从文章主题提取的小写标签>]
description: "<准确概括文章范围的一句话摘要>"
---

1. Table of Contents, ordered
{:toc}

<从具体场景、背景或问题张力自然切入>

## <按知识依赖确定的第一节>

<正文>

## <自然承接上一节的后续章节>

<正文>
```
